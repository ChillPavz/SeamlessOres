# Seamless Ores

Ore variants matched to the stone around them. Iron in granite looks like iron in granite rather than
iron in a grey stone block pasted into granite. For Minecraft **1.20** through **26.3** on **Fabric**,
**NeoForge** and **Forge**: see [Versions](#versions) for exactly which.

## How it works

- **The ore stays where it was.** Veins are not added, moved or made more common. A block that becomes
  granite iron ore was already going to be iron ore; only its look changes.
- **Vanilla stones**: granite, diorite, andesite, tuff and dripstone, plus basalt and blackstone in the
  Nether, the Sulfur Caves' cinnabar (26.2 and 26.3, and with Vanilla Backport on 1.21.1 and 1.20.1),
  and the deep blackstone Terralith lays in its caves.
- **Other mods' stones**: Blockus, Born in Chaos, Create, Create: TFMG, Forbidden and Arcanus, Let's Do Meadow,
  Mythic Upgrades, Promenade, Spawn, Twigs and Wilder Wild, each with the ores that really form inside
  it, on the versions and loaders those mods exist for.
- **Other mods' ores**: Cobblemon, Create, Create: New Age, Create: TFMG, Dense Mekanism, Energized
  Power, Exp Ores, Extreme Reactors, Ice and Fire (Community Edition), Immersive Engineering, Malum, Mekanism, Modern
  Industrialization, Mystical Agriculture, Mythic Metals, Mythic Upgrades, Occultism, Oreganized,
  Powah, Silent Gear, Silent's Gems, Tech Reborn and Things.
- **A modded block exists only when its mods are installed.** Each variant copies the tags, drops,
  experience, hardness and mining level of the ore it replaces.
- **What changes the amount of ore** has its own switch: copper thinning, Lush Caves clay and moss,
  the Sulfur Caves, cinnabar ores, the Nether's basalt and blackstone ores, and the Geology option
  (off by default), which stops ore forming in vanilla stones it could never form in. Ores in other
  mods' stones always follow a fixed geology rule.

The full block list of each version, with ids, is in that version's README (table below).

## Seamless Ores: Matrix

Matrix, the separate mod for other mods' stones, is now part of Seamless Ores. Its block ids are
carried over: once Matrix is removed, its blocks and items in a world become Seamless Ores' own. While
both are installed, Seamless Ores leaves Matrix's stones to Matrix, so nothing generates twice.

## Building

Each folder is its own Gradle build, because each needs a different Gradle, plugin set or JDK. Code,
tools and overlay art that every version shares live once, in `shared/`.

| Folder | JDK to run Gradle | Command |
|---|---|---|
| `26.x` | 25 | `./gradlew build -Pmc=26.3`, `./gradlew build -Pmc=26.1.x`, then `python tools/merge_bands.py` |
| `1.21` | 24 | `./gradlew build -Pmc=1.21.1` (and `1.21.11`), or `py -3 tools/build_all.py` |
| `1.20.1` | 22 | `./gradlew build` |

`26.x` makes one jar per loader for every 26.x version from two builds. `1.21` builds two bands from
one tree: what differs lives in `src/<band>` inside each module, and `versions/<band>.properties`
holds every version number. Block models, loot tables, tags and the block lists are generated by
each folder's `tools/generate_assets.py`. Jars land in each loader's `build/libs`.
